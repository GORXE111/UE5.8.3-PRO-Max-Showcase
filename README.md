# UE 5.8.3 PRO Max

UE 5.8.3 PRO Max 是团队内部使用的 Unreal Engine 定制项目。本仓库公开展示开发方向和进度，**不提供 Epic 引擎源码、第三方 SDK、插件文件或引擎安装包**。完整源码在私有仓库中，由具备相应 Unreal Engine 访问资格的团队成员协作维护。

> 截至 2026 年 9 月 24 日：功能处于源码开发阶段。团队尚未编译引擎、启动编辑器验证这些改动，也未运行功能测试或打包。下表中的“已加入”只表示源码已提交，不表示功能已通过验收。

## 开发方向与当前进度

| 方向 | 已加入的源码工作 | 待验证内容 |
| --- | --- | --- |
| AI 控制编辑器 | 基于 UE 自带的实验性 MCP 功能，加入可选的 Actor 查询与受控重命名工具 | 插件发现、Codex 连接、撤销和权限开关 |
| GAS 游戏框架 | 可复用技能集合、按标签激活与查询技能，以及可选的行为树节点 | 编辑器创建、多人游戏复制与预测、项目接入 |
| Excel 配置表 | XLSX 分端导出：客户端二进制、服务器 JSON；提供 UE 按 ID 读取的接口 | UE 内实际读取、项目打包和字段分端 |
| 渲染 | 保留 UE 原生 Lumen、硬件光追和 TSR；加入可选渲染档位、NVIDIA 功能适配层及一项 Lumen 参数保护 | RTX 40 实机画质、性能、回退和稳定性 |

NVIDIA 官方 DLSS 插件由开发者按许可在本机安装，不放入此仓库。RTX 40 是优先兼容目标，但尚未完成实机验证。DLSS 5 尚未接入。

## 工作方式

- 完整引擎仓库保持私有。受邀协作者须具备相应版本 Unreal Engine 的访问资格。
- 本展示仓库只收录团队原创的项目介绍和进度文档。公开阅读不等于获得引擎源码或定制编辑器。
- 引擎新功能优先做成可关闭的插件或小范围改动，保留 UE 原生路径。
- 构建、测试和打包将在团队明确安排后进行；此前不把源码阶段成果称为稳定版本。

后续工作见 [开发路线](ROADMAP.md)。Unreal Engine 源码访问与共享规则见 [Epic 官方说明](https://www.unrealengine.com/ue-on-github)。
